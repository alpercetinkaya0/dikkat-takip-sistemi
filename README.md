# Dikkat Takip Sistemi (Attention Tracking System)

Bu proje, kamera görüntüsü üzerinden gerçek zamanlı olarak dikkat ve odaklanma durumunu analiz eden Python tabanlı bir  yapay zeka uygulamasıdır. 

##  Projenin tanıtımı
OpenCV kütüphanesi sayesinde Yüzde gözleri bulur ve gözlerin açık yada kapalı olduğunu eğitildiği yaklaşk 84 bin fotoğraflı veri seti sayesinde anlar.
İki gözün 5 saniye boyunca kapalı olduğunu anlar veya 5 saniye boyunca gözleri göremezse iki gözün de açık olduğunu algılayana kadar alarm verir.

##  Kullanılan Teknolojiler
* **Programlama Dili:** Python
* **Kütüphaneler:** Görüntü işleme, veri analizi ve derin öğrenme/yapay zeka kütüphaneleri (OpenCV vb.)
